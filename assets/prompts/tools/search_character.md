查动漫 / 游戏角色的 Danbooru tag（不含 OC，OC 用 search_oc）。query / origin 至少传一个:
  query: 角色名（中文或英文），如 "芙兰朵露" / "flandre"
  origin: 出处，如 "东方" / "原神"；知道出处就和 query 一起传，用来消除重名
  limit: 返回上限，默认 10
何时调:
  - 必调: 用户提到角色名，且 [角色候选] 块里没有对得上的
  - 禁止: 凭记忆直写角色 tag
返回: tag 是写进提示词的角色 tag；zh 是中文名；origin 是出处；post_count 是热度，越大模型画得越准，用户没点名冷门的那个就选热度高的；wiki 是一句话介绍，可能为空
预取块 [角色候选]: 按用户原文字面匹配出来的候选，很容易误命中；几条候选不代表用户点了几个角色，对不上就忽略
