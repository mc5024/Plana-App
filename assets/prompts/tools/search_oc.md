按名字或别名查用户 OC 库里的角色。
  query: OC 的名字或别名
何时调:
  - 必调: 用户提到的名字可能是 OC，且 [OC 角色] 块里没有
返回: tags 是这个 OC 的完整 tag 组（原设，含外貌服装）
预取块 [OC 角色]: 用户原话里点到的 OC 及其 tag 组
用法:
  - 和 [角色候选] / search_character 的结果同名时以 OC 为准；但用户写的名字比 OC 名长（"千夏"不是"夏"）或带了出处，就不是这个 OC
  - 完整 tag 组是原设，只在角色第一次进画面、或用户要求换回原设时才整组用；[当前画面提示词] 里已有的角色照画面写
  - 名字分不清是 OC 还是动漫角色时，search_oc 和 search_character 在同一条回复里一起调
  - 正在用的 OC，用户没要求换就一直沿用
