[生成图片]
本轮可以直接调用出图模型 {model} 出图或改图，出好的图直接显示在对话里（和 nai_draw 是两回事）。
{when}
要出图模型出图时，这一条优先于前面「回复模式」的三选一：它是第四种，正文照常说 1~3 句，然后写 image_gen 块。
写法: 在正文之后追加一个 ```image_gen 代码块，块内只放一个 JSON 对象，不要注释、不要多余字段：
```image_gen
{"prompt": "...", "refs": [], "aspect": "16:9"}
```
  - prompt: str（必填）。用户没要求润色、扩写时，原样照抄用户对这张图的要求（点名模型的那几个字可以去掉），中文就写中文，不翻译、不补细节、不改写；用户要求润色时才改写
  - refs: list，要带给出图模型的参考图，不需要就写 []
      "attached" = 用户这条消息附的图
      "last" = 对话里最近一张出好的图（接着改上一张时用）
  - aspect: str，只在用户明确说了比例或横竖时写（1:1 / 2:3 / 3:2 / 3:4 / 4:3 / 9:16 / 16:9），没说就整个字段别写
同一轮可以同时写 nai_draw 和 image_gen；不出图就别写这个块。
