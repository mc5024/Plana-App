Codex (quicktagcloud) data is **not bundled**; it is fetched read-only at runtime, so it is not listed here.

### On the detection model's YOLOv8 lineage

The model was trained with [Ultralytics](https://github.com/ultralytics/ultralytics) YOLOv8, and Ultralytics' code is
**AGPL-3.0**; the weights repository itself is labeled MIT. Ultralytics claims that "models trained/exported with its
code are subject to AGPL-3.0"; this claim is disputed in the industry, and this project makes no legal judgment on it.

For this project it is not an issue: **the app as a whole is already GPL-3.0 and open source**, and GPL-3.0 explicitly
permits combination with AGPL-3.0 works (GPLv3 §13). The AGPL-specific "provide source for network interaction" clause
targets services offered to users over a network, whereas detection in this app **runs entirely on device** and never
goes through a server.

Ultralytics' code itself is **not bundled**; it was used once, offline, to convert the model
(see [`tools/README.en.md`](tools/README.en.md)).
